# 00-research-toolkit

How-to guides for research at FIMA Lab (NYCU): data access, tools and set-up.
For lab members and for students in our courses. One folder per tool.

| Guide | What it covers |
|---|---|
| [wrds/](wrds/README.md) | WRDS: get an NYCU account, download data, query from Python, licence rules, data WRDS does not have |

## Rules for every guide

- How-to only. No licensed data, no downloaded files, no passwords, keys or tokens. This repository is public.
- Write for a newcomer: short steps, one idea per line, a working example.
- Date what can change (links, forms, contacts) and say whom to ask when it breaks.
