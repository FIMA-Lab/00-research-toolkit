# 00-research-toolkit

How-to guides for research at FIMA Lab (NYCU): data access, computing and set-up.
For lab members and for students in our courses.

| File | What it covers | Language | Written |
|---|---|---|---|
| [WRDS-claude.md](WRDS-claude.md) | **Start here for WRDS.** NYCU account, download from the website, query from Python, licence rules, what to do when the data is not on WRDS (e.g. Bloomberg) | English | 2026-10, current |
| [WRDS-teng.md](WRDS-teng.md) | The earlier WRDS walkthrough, step by step with screenshots of the query form | 中文 | earlier; kept for the screenshots |
| [TEJ-teng.md](TEJ-teng.md) | TEJ (Taiwan market data): quick-start links, API, and a worked example downloading daily mutual-fund prices | 中文 | 2021 (李國誠, reviewed by Teng) |
| [NCHC-teng.md](NCHC-teng.md) | NCHC / TWCC (國網中心) cloud computing: register, join the lab's project, run Jupyter in a container, upload files, delete containers to save credit | 中文 | 2023 (Ian Lee, reviewed by Teng) |

Which one do I need?
- US stock, accounting, analyst or option data → WRDS.
- Taiwan stocks, funds or firms → TEJ.
- Your code needs a GPU or more memory than your laptop → NCHC.

## Rules for every guide

- How-to only. No licensed data, no downloaded files, no passwords, keys, tokens or student ids. This repository is public.
- Write for a newcomer: short steps, one idea per line, a working example.
- Date what can change (links, forms, contacts) and say whom to ask when it breaks.

Maintained by Prof. Huei-Wen Teng (鄧惠文), FIMA Lab, NYCU.
